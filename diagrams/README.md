# Kordra Architecture Diagrams

This folder contains visual representations of Kordra's architecture and workflows.

## Diagrams

1. **[architecture-overview.md](architecture-overview.md)** - High-level system architecture
2. **[agent-lifecycle.md](agent-lifecycle.md)** - Agent execution lifecycle
3. **[workflow-example.md](workflow-example.md)** - Example workflow execution

## Format

Diagrams are provided in ASCII art format for:
- Easy version control
- Text-based viewing
- No external tool dependencies
- Quick understanding without graphics software

For production presentations, these can be converted to:
- Mermaid diagrams
- PlantUML
- Draw.io
- PNG/SVG images
